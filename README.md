# Online Real Estate Management System

## Project Overview

The Online Real Estate Management System is a Java-based web application developed to simplify property listing and management. It provides a centralized platform for managing property information and supporting real estate-related activities.

## Technologies Used

- Java 21
- Spring Boot 3
- Spring Data JPA
- Spring Security
- JDBC
- Thymeleaf
- Bootstrap 5
- Maven
- H2 Database

## Key Features

- Property listing and information management
- Web-based user interface
- Database integration for storing application data
- Server-side application development using Spring Boot
- Responsive interface using Thymeleaf and Bootstrap

*Note: Include additional features, such as user roles, rental applications, or lease management, only if they are implemented in your project.*

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/logpepperred/online-real-estate-management-system.git
   ```

2. Navigate to the project directory:

   ```bash
   cd online-real-estate-management-system
   ```

3. Start the application using your configured run script:

   ```bash
   ./run.sh
   ```

4. Open your browser at:

   ```text
   http://localhost:8080
   ```
